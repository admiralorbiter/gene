# GENE Podcast Packet

## Purpose

This packet is designed to be uploaded to a Google/NotebookLM-style podcast generator to produce a **40–50 minute, high-density conversational episode** about GENE (Genealogical Epistemic Network Experiments), the research that motivated it, what Experiment 0 actually found, and the larger scientific and philosophical questions it opens.

The intended episode is not a product demo and not a dry paper summary. It should feel like two curious, technically literate hosts discovering that a deceptively simple question — **“what happens when a memory is wrong?”** — connects information theory, genetics, epidemiology, reconstructive human memory, error-correcting codes, philosophy of science, and modern LLM agent architectures.

## Recommended upload order

1. `00_PODCAST_GENERATION_BRIEF.md` — instructions to the podcast model.

7. `06_SOURCE_LIBRARY.md` — curated bibliography and links.

## Central podcast question

> **If a memory is wrong but a reasoning system uses it perfectly, where exactly does the error live — and what happens when that error is allowed to reproduce?**

## The simplest description of GENE

GENE is an experimental system for giving information a **family tree**.

It distinguishes:

- what information was exposed to a model;
- what information the model *said* it used;
- what information was actually behaviorally necessary under intervention;
- whether a resulting claim is true in the canonical world;
- whether it is nevertheless perfectly derivable from the agent's local memory;
- how mutated information changes, propagates, repairs, or dies across memory generations.

Experiment 0 is frozen and calibrated. Experiment 1 is the next stage and is concerned with multi-generation propagation. **Do not invent Experiment 1 results if they are not provided in an updated packet.**

## A useful recurring motif

A system can be:

- perfectly deterministic,
- perfectly logically consistent,
- perfectly faithful to its memory,

…and still be wrong if the memory it inherited was wrong.

That is the doorway into the episode.
