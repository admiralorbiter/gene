# GENE Decision Log

Record material research/design decisions here. Do not rewrite old entries; append a new decision when something changes.

---

## D-001 — Project name

**Date:** 2026-08-19  
**Status:** accepted

**Decision:** Use **GENE — Genealogical Epistemic Network Experiments** as the working project name.

**Reason:** The project studies the ancestry, reproduction, mutation, repair, and persistence of information across generated memory lineages.

---

## D-002 — Synthetic ground truth first

**Date:** 2026-08-19  
**Status:** accepted

**Decision:** Initial experiments use procedurally generated fictional worlds with exact canonical truth rather than real-world factual corpora.

**Reason:** Causal lineage evaluation requires a trustworthy oracle and known valid derivation paths. Real-world ambiguity would confound the instrumentation before it is validated.

---

## D-003 — Three lineage types

**Date:** 2026-08-19  
**Status:** accepted

**Decision:** Record exposure lineage, model-reported support lineage, and causal lineage separately.

**Reason:** Context exposure is objective, model attribution is observational, and causal influence requires intervention. Collapsing them would overstate what the system knows.

---

## D-004 — Experiment 0 before biological defenses

**Date:** 2026-08-19  
**Status:** accepted

**Decision:** Validate lineage observability before implementing senescence, apoptosis, source anchoring, reproduction gating, or other biology-inspired controls.

**Reason:** Interventions are uninterpretable if the system cannot reliably observe what reproduced from what.

---

## D-005 — Experiment 1 primary endpoint candidate

**Date:** 2026-08-19  
**Status:** provisional until pilot freeze

**Decision:** Use **cumulative causally infected descendants through generation 8** as the leading candidate primary endpoint for the first serious Experiment 1 pilot/confirmatory design.

**Reason:** It directly measures mutation amplification while retaining causal ancestry as a requirement.

---

## D-006 — Do not reuse the name Epistemic Reproduction Number as a novelty claim

**Date:** 2026-08-19  
**Status:** accepted

**Decision:** Use working notation `R_mem` internally for memory-lineage reproduction.

**Reason:** A June 2026 preprint already uses **Epistemic Reproduction Number** \(R_E\) for false-positive cascades in autonomous scientific networks. GENE should position itself around empirical lineage measurement rather than terminology ownership.
